# jamalwilliams.com — Personal Brand Site

> Astro site for Sovereign Architect personal brand. High-contrast, cinematic design.

## Tech Stack

- Astro 5.x, TypeScript
- Cloudflare Pages (deploy)
- Tailwind CSS

## Commands

```bash
npm run dev          # local dev
npm run build        # production build
npm run preview      # preview build
npm run astro        # astro CLI
```

## Content

Repository-local content. Site pages, posts, config, and media live under `src/content/` and `public/`; do not point loaders or media paths at the Vault website mirror.

- astro-component-generator
